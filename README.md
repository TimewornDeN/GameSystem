# GameSystem

Проста текстова гра з консольним інтерфейсом (.NET 10). Можна створювати персонажів, предмети й вміння,
брати персонажів із віддаленої бази, битися двома персонажами, зберігати гру та результати боїв.

## Запуск

```
dotnet run --project GameSystem.CLI
dotnet test
```

Далі в програмі: `help` покаже всі команди, `exit` вийде.

## Швидкий приклад

```
create char          # діалог: ім'я та клас
create char
ls char              # таблиця персонажів
play                 # вибрати двох бійців і почати бій (у бою: attack, heal, defend, ability, status, surrender)
results              # історія боїв
save mygame          # зберегти стан персонажів
```

## Проєкти

| Проєкт | Призначення |
|---|---|
| `GameSystem.Core` | правила гри, бій, текстова система, інтерфейси |
| `GameSystem.Infra` | консоль, JSON-файли, HTTP-клієнт, рендер тексту |
| `GameSystem.CLI` | командний інтерфейс (фасад, стратегії, команди, рендерери) |
| `GameSystem.ConsoleApp` | автоматична симуляція бою |
| `GameSystem.FileManager` | файловий менеджер (практична 12) |
| `GameSystem.Tests` | тести |

Опис архітектури та командного інтерфейсу: [docs/DESIGN.md](docs/DESIGN.md).
